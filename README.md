# ⚡ TaskDo — Task Management App

A sleek, responsive, and feature-rich **Kanban-style To-Do Application** built with pure Vanilla JavaScript, modern CSS3, and HTML5. Designed to help users organize, track, and visualize their daily workflow seamlessly.

## ✨ Key Features

- 📋 **Kanban Board Layout:** Categorize tasks easily into `To Do`, `In Progress / Important`, and `Completed` columns.columns with native HTML5 Drag and Drop integration.
- 🌓 **Dark / Light Theme:** Toggle seamlessly between dark and light modes with auto-saved theme preferences in `localStorage`.
- 📊 **Dynamic Completion Progress Bar:** Real-time calculation and visualization of task progress.
- 💾 **Persistent Data (LocalStorage):** Automatic saving ensures tasks and states persist across browser refreshes.
- 🔍 **Live Search & Filtering:** Quick search bar to locate specific tasks in real-time.
- 📱 **Fully Responsive Design:** Optimized for all screen sizes, from mobile phones to high-resolution desktops.
- 🎨 **Modern Dark-Centric UI:** Crafted with CSS custom properties (variables), subtle backdrop blurs, and clean animations.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties, CSS Grid, Flexbox), JavaScript (ES6+ Modules & LocalStorage API).
- **Icons:** FontAwesome v6.
- **Typography:** Modern Sans-Serif stack (`Arial`, system fallbacks).
